# Recycle Map

Recycle Map is a platform created to make it easier to find waste collection points in Cachoeira do Sul (Brazil), and discover where to take different types of materials.

## About the project

The idea for Recycle Map came from a simple problem: finding where to take different types of materials for disposal is not always easy.

The project was created to make the city's waste collection infrastructure more visible by bringing this information together in an interactive map.

The current version allows users to explore collection points by category, view information about each location, and open a route to the selected point.

## Data

The collection point data currently displayed on the map is fictional and is used exclusively to demonstrate how this type of information could be organized and accessed by the community.

The project was designed with the intention of using real collection point data from Cachoeira do Sul when this information becomes available.
